OpenAI gpt-image-2

יצירה ועריכת תמונות עם המודל החדש של OpenAI. השלמה ליום 1 (Gemini 3 Pro) — לבחור לפי סגנון, מחיר או פשוט אם אין לכם מפתח Gemini.

חובה לפני שמתחילים

Organization Verification

המודל gpt-image-2 דורש אימות ארגון ב-OpenAI. בלי השלב הזה, כל קריאה ל-API תיכשל. זה תהליך חד-פעמי שלוקח עד 15 דקות להפעלה.

לכו ל-platform.openai.com/settings/organization/general → לחצו Verify Organization → השלימו את תהליך אימות הזהות → חכו עד 15 דקות.

התקנה

3 שלבים להתקנה

1

קבלו מפתח API מ-OpenAI

לכו ל-platform.openai.com/api-keys → לחצו Create new secret key → העתיקו את המפתח (מתחיל ב-sk-) ושמרו במקום בטוח. תדביקו אותו ל-Claude Code בשלב 3.

2

השלימו Organization Verification

ראו את האזהרה בראש הדף. בלי השלב הזה, gpt-image-2 לא יעבוד. חובה, חד-פעמי, לוקח עד 15 דקות.

3

התקנה מלאה בפרומפט אחד

פתחו שיחה חדשה ב-Claude Code, הדביקו את הפרומפט הבא והחליפו YOUR_KEY_HERE במפתח שלכם משלב 1. Claude יטפל בכל השאר:

  • יוריד את הסקיל מ-GitHub
  • ישמור את המפתח שלכם כמשתנה סביבה קבוע (עובד בכל פרויקט, לתמיד)
  • יתקין את ה-SDK
  • ייצור תמונת בדיקה לוודא שהכל עובד
העתיקו ל-Claude Code — החליפו YOUR_KEY_HERE קודם
Install the gpt2-image skill from https://github.com/guyaga/10d10s-bonus-gpt2-image. My OpenAI API key is: YOUR_KEY_HERE. Please save this key as a permanent environment variable on my system (OPENAI_API_KEY) so it persists across all terminals and projects. Then run `npm install openai --prefix ~/.claude/skills/gpt2-image` to install the SDK. Finally, verify it works by generating a test image: a photorealistic beige coffee mug on a wooden table, save to test-mug.png.
למה המפתח בפרומפט?

זאת הגדרה חד-פעמית. Claude שומר את המפתח כמשתנה סביבה קבוע במערכת שלכם (setx ב-Windows, .zshrc/.bashrc ב-Mac/Linux) — המפתח לא נשלח לשום מקום חיצוני, זה קורה רק על המחשב שלכם. אחרי זה, הסקיל פשוט עובד בכל פרויקט בלי שתצטרכו לחזור לפרומפט הזה.

אם הכל עבר בסדר, אמורה להיות לכם תמונה של ספל קפה בתיקייה שפתחתם.

פתרון בעיות

אם משהו לא עובד

"Organization must be verified"

לא השלמתם את תהליך האימות. חזרו לאזהרה בראש הדף וסיימו את השלב הזה. חכו 15 דקות.

"Connection error" בפרומפטים ארוכים

לפעמים gpt-image-2 נוטש בשקט על פרומפטים מורכבים ב-quality=high. תנסו quality=medium עם פרומפט יותר קצר — ב-90% מהמקרים זה פותר.

"Cannot find module 'openai'"

הריצו בטרמינל: npm install openai --prefix ~/.claude/skills/gpt2-image
