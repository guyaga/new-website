Storyboard Studio

Video Storyboard · Gemini 3 Pro

צינור הפקה מלא של סטוריבורד לוידאו — מקונספט במשפט אחד ועד תוצר HTML/PDF מוכן ללקוח. דמות ראשית + אביזרים + לוקיישנים + 5–15 תמונות סצנה עם עקביות דמות נעולה בכל שוט, פלוס פרומפטים של VEO 3.1 ו-Kling 3.0 מוכנים להדבקה.

דרישה מקדימה

יום 1 חייב להיות מותקן קודם

הבונוס הזה משתמש בסקיל nano-banano-pro ובמשתנה הסביבה GEMINI_API_KEY — בדיוק אלה שהתקנתם ביום 1 של הקורס. אם סיימתם את יום 1, אתם מוכנים. אם לא, חזרו ליום 1 ואז לכאן.

מה מקבלים מריצה אחת

התוצר השלם

בתיקייה שאתם בוחרים, לכל פרויקט:

  • <project>/
  • ├── SCRIPT.md — טבלת סצנות + טון + style bible
  • ├── SCENE_PROMPTS.md — VEO 3.1 + Kling 3.0 לכל סצנה
  • ├── STORYBOARD_PRESENTATION.html — התוצר בעיצוב שוויצרי
  • ├── actors/hero_reference.png
  • ├── props/*.png — מבודדים על רקע לבן
  • ├── locations/*.png — שוטי establishing
  • └── horizontal_16x9/scene_NN.png — תמונה לכל שוט

פותחים את ה-HTML בדפדפן → Ctrl+P → Save as PDF. זה התוצר ששולחים ללקוח.

התקינו את הסקיל

פתחו שיחה חדשה ב-Claude Code והדביקו את הפרומפט הבא. Claude יוריד את הסקיל ויתקין את ה-SDK של Gemini.

הדביקו ב-Claude Code
Install the storyboard-studio skill from https://github.com/guyaga/10d10s-bonus-storyboard-studio and run `npm install @google/genai --prefix ~/.claude/skills/storyboard-studio` to install the SDK.

הריצו את הסטוריבורד הראשון שלכם

בקשו מ-Claude בצורה טבעית. לא צריך CLI, לא צריך לזכור פקודות. לדוגמה:

פרומפט לדוגמה
Use the storyboard-studio skill to plan a 30-second IG Reel about a baker opening her Jerusalem bakery at dawn. Auto mode. Save to ./bakery-test/

Claude ישאל כמה שאלות קצרות (מצב, טון, אורך סצנה) ואז ירוץ לבד כ-15 דקות. בסוף: תיקייה מלאה עם HTML מוכן.

שלושה מצבי עבודה

כמה מעורבות אתם רוצים?

AI יוצר הכל

מתחילים מקונספט בלבד. AI יוצר את הדמות, האביזרים והלוקיישנים. אתם מאשרים את הבריף ואז הוא רץ לבד.

מודרך (ברירת מחדל)

מעלים מה שיש, AI ממלא

יש לכם לוגו, תמונת מוצר, תמונה שלכם? שחררו ב-inputs/. Claude יזהה ויפיק רק את מה שחסר.

רפרנס בלבד

רק בקבצים שלכם

אתם מעלים הכל — דמות, אביזרים, לוקיישנים. AI לא מייצר כלום חדש, רק מחבר את הסצנות מהקבצים שלכם.

הסוד של עקביות הדמות

איך אותה דמות נשארת אותה דמות ב-10 שוטים שונים?

זה הדבר הכי קשה ביצירת סטוריבורד עם AI. הסקיל פותר את זה בשלוש דרכים:

  • דיוקן דמות על רקע לבן — נוצר פעם אחת בהתחלה, מהווה סימוכין נעול לכל השוטים
  • תיאור מילולי זהה — אותו טקסט תיאור בדיוק מודבק בכל פרומפט סצנה
  • הצמדת תמונת סימוכין — דיוקן הדמות מוצמד פיזית לכל קריאת API של סצנה. Gemini מתאים את הפנים, השיער, הבגדים, המידות

פלוס הצמדת לוקיישן + אביזרים רלוונטיים לכל סצנה — ככה גם הם נשארים עקביים.

פתרון בעיות

אם משהו לא עובד

GEMINI_API_KEY not set

לא סיימתם את יום 1. חזרו ליום 1 של הקורס, הגדירו את המפתח ככמשתנה סביבה קבוע, ואז נסו שוב.

הפנים של הדמות משתנות בין סצנות

בדקו שבקובץ brief.json, לכל סצנה יש refs שכוללים את actors/hero_reference.png. זה החיבור הקריטי.

fetch failed על סצנה מסוימת

שגיאת רשת זמנית ב-Gemini. הסקיל מנסה 3 פעמים עם המתנה של 5 שניות. אם זה ממשיך — הריצו רק את הסצנה הכושלת עם --phase scenes.
