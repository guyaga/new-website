Day 04

יצירת וידאו עם AI

fal.ai MCP

בשיעור הזה נלמד ליצור סרטוני AI מקצועיים ישירות מ-Claude Code — מטקסט או מתמונה, עם המודלים הטובים בעולם: Veo 3.1, Kling 3, Seedance ועוד. נכיר גם מה זה MCP ואיך הוא הופך את Claude לכלי חזק יותר.

מה זה MCP?

תוספים ל-Claude Code

MCP (Model Context Protocol) זה כמו תוסף (Plugin) ל-Claude Code. בדיוק כמו שתוספים לכרום מוסיפים יכולות לדפדפן, MCP מוסיף יכולות ל-Claude. במקרה הזה — גישה למאות מודלים של יצירת וידאו דרך fal.ai.

פקודה אחת להתקנה. ואז Claude יכול ליצור סרטונים.

כמה זה עולה?

תמחור

חשוב לדעת

יצירת וידאו עם AI עולה כסף לכל שנייה. סרטון של 5 שניות יכול לעלות $0.35 עד $2. זה עדיין זול דרמטית בהשוואה לצילום מסורתי (צלם, שחקנים, עריכה), אבל חשוב להיות מודעים לעלויות.

מודלמחיר/שנייהלמה מתאים
Veo 3.1$0.20-0.40האיכות הכי גבוהה, המודל של גוגל
Kling 3 Pro$0.11-0.20קולנועי, עם אודיו מובנה
Kling 2.5 Turbo~$0.07יחס מצוין של מהירות/איכות
Veo 3.1 Liteזול יותרגרסה חסכונית של Veo
טיפ חיסכון

התחילו עם מודלים זולים (Kling 2.5, Veo Lite) לבדיקות. רנדרו סופי עם מודל פרימיום רק כשהפרומפט והתמונה מושלמים.

לפני שמתחילים

שלב מקדים — קבלת מפתח fal.ai

לפני שמריצים שום פקודה, צריך חשבון fal.ai עם קרדיטים ומפתח API. השלב הזה חייב להיות לפני שלב 1.

א

הירשמו ב-fal.ai

לכו ל-fal.ai וצרו חשבון חדש.

ב

הוסיפו קרדיטים ($5-10 להתחלה)

לכו ל-fal.ai/dashboard/usage-billing/credits והוסיפו $5-10 — מספיק ל-20-50 בדיקות קצרות.

ג

צרו מפתח API

לכו ל-fal.ai/dashboard/keys, לחצו Create Key, ושמרו את המפתח במקום בטוח. תדביקו אותו בשלב 1.

תקציב

יצירת וידאו AI עולה כסף לפי שניה. התחילו עם $5-10 וכדי לבדוק עם מודלים זולים (LTX, Kling 2.5) לפני שמשתמשים במודלים פרימיום (Veo 3.1, Kling 3 Pro).

התקנה

4 שלבים להתקנה

1

הוסיפו את שרת ה-fal MCP — גלובלית

הריצו את הפקודה הבאה באחת משתי האפשרויות:

(א) בטרמינל רגיל (PowerShell, Terminal, Command Prompt), או

(ב) בשיחה חדשה לגמרי ב-Antigravity — הדביקו כהודעה ראשונה ו-Claude יריץ אותה (אשרו אם נשאלים)

העתיקו — הריצו בטרמינל או הדביקו בשיחה חדשה ב-Antigravity
claude mcp add --transport http fal-ai https://mcp.fal.ai/mcp --header "Authorization: Bearer YOUR_FAL_KEY" --scope user

החליפו YOUR_FAL_KEY במפתח האמיתי שיצרתם בשלב המקדים. אמורה להופיע הודעת הצלחה כמו Added HTTP MCP server fal-ai to user config.

2

בדקו שה-MCP מחובר

פתחו שיחה חדשה ב-Claude Code או ב-Antigravity.

חשוב!

גם אם השתמשתם ב-Antigravity לשלב 1, אתם חייבים לפתוח עוד שיחה חדשה עכשיו — Claude טוען MCP רק כשהשיחה מתחילה, אז השיחה שהריצה את הפקודה לא תזהה את ה-MCP החדש.

בשיחה החדשה, בדקו שה-MCP הותקן:

  • ב-Antigravity — הקלידו / כדי לפתוח את תפריט הפקודות, ואז בחרו mcp servers מהרשימה
  • בטרמינל (Claude Code CLI) — הקלידו /mcp ישירות

בשני המקרים, אמור להופיע fal-ai עם סימן ירוק ✓ Connected.

בדיקת זהב — פרויקט אחר

פתחו תיקייה אחרת לגמרי (שולחן העבודה, פרויקט אחר — כל מה שלא קשור לקורס), פתחו שיחה חדשה, ובדקו שוב. אם fal-ai עדיין שם — ההתקנה הגלובלית עובדת. אם הוא נעלם, פספסתם את --scope user — הריצו שוב את שלב 1.

אם fal-ai לא מופיע בכלל

הריצו claude mcp get fal-ai בטרמינל — אמור להראות Scope: User config (available in all your projects). אם כתוב "Local config", הריצו שוב את שלב 1 עם --scope user. אם לא מופיע בכלל, הסיבה הנפוצה ביותר היא שגיאת הקלדה ב-API Key.

3

התקינו את הסקיל

באותה שיחה חדשה שבה ווידאתם ש-fal-ai מופיע ברשימת ה-MCP, הדביקו את הפרומפט הזה:

העתיקו — הדביקו בשיחה החדשה
Install the fal-ai-video-generation skill from https://github.com/guyaga/10d10s-day04-video-generation and verify the fal MCP is connected by searching for available video models.

Claude יוריד את הסקיל ל-~/.claude/skills/ ויריץ חיפוש מודלים דרך ה-MCP כדי לוודא שהכל עובד. אמורים להופיע Veo 3.1, Kling 3, Seedance, LTX ועוד.

4

צרו את הסרטון הראשון שלכם

התחילו עם מודל זול (LTX או Kling 2.5) כדי לכוונן את הפרומפט, ואז שדרגו למודלים פרימיום (Veo 3.1, Kling 3 Pro) כשזה נראה טוב. נסו את זה:

פרומפט ראשון — בדיקה זולה
Generate a 5-second test video using LTX Video: A slow aerial drone shot over a futuristic city at sunset, neon lights reflecting on glass buildings, cinematic. Save to D:/Videos/test1.mp4

עלות: ~$0.10. אם אתם אוהבים את התוצאה, צרו שוב עם Veo 3.1 או Kling 3 Pro לאיכות גבוהה יותר.

מה אפשר לעשות

4 תהליכי עבודה

WORKFLOW 01

טקסט → וידאו

תארו מה אתם רוצים לראות — ה-AI יוצר את הסרטון.

Generate a 5-second video using Veo 3.1: "A slow aerial drone shot over a futuristic city at sunset, neon lights reflecting on glass buildings, cinematic"
WORKFLOW 02

תמונה → וידאו (התוצאות הכי טובות)

צרו תמונה עם סקיל יום 1, ואז הנפישו אותה לסרטון.

1. First, use nano-banano-pro to generate a still frame: "Professional woman presenting at tech conference, dramatic stage lighting" 2. Then animate it with Kling 3: "She gestures confidently, camera slowly zooms in, subtle audience movement"
WORKFLOW 03

פריים ראשון + אחרון (שליטה מלאה)

צרו תמונת פתיחה וסיום — ה-AI ייצור את התנועה ביניהן.

1. Generate first frame: "A closed laptop on a desk, morning light" 2. Generate last frame: "Same laptop now open with dashboard, coffee cup appeared" 3. Use Veo 3.1 first-last-frame-to-video to generate the transition
WORKFLOW 04

צינור הפקה מלא (ימים 1-5)

השתמשו בכל מה שלמדתם עד עכשיו ליצירת סרטון מלא.

Let's create a complete product video: 1. Generate a hero image (Day 1 - nano-banano-pro) 2. Animate it into 5-second video (Day 4 - Kling 3) 3. Check quality (Day 2 - ai-video-analyzer) 4. Add subtitles and resize (Day 3 - ai-video-editor) 5. Add voiceover (Day 5 - ai-voice-audio)
לפני שמייצרים

צ'קליסט — כדי לא לבזבז כסף

עברו על הרשימה הזו לפני כל יצירת וידאו:

  • הפרומפט ספציפי? — תנועה, מצלמה, מצב רוח, אורך
  • התמונה באיכות גבוהה? — מינימום 2K לתמונה-לוידאו
  • המודל מתאים? — זול לבדיקות, פרימיום לסופי
  • האורך סביר? — התחילו עם 4-5 שניות לבדיקה
  • יש מספיק קרדיטים? — בדקו ב-fal.ai dashboard
עצה חשובה

תהיו מעורבים בכל שלב — בדקו את איכות התמונה, את הפרומפט, את המודל שנבחר. כל דבר שמשפיע על התוצאה שווה בדיקה לפני היצירה. אל תסמכו על Claude באופן עיוור — זה הכסף שלכם.
